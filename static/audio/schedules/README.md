# Audios web del gestor de horarios

Estos archivos se usan para previsualizar audios desde la plataforma web.

Coloca aquí los MP3 con estos nombres exactos:

- `schedule_changed.mp3`
- `temporarily_unavailable.mp3`
- `special_day.mp3`

La vista del editor de horarios ya apunta a estas rutas estáticas:

- `/static/audio/schedules/schedule_changed.mp3`
- `/static/audio/schedules/temporarily_unavailable.mp3`
- `/static/audio/schedules/special_day.mp3`

Mantén estos MP3 como copia ligera para el navegador. Los formatos para
Asterisk deben prepararse por separado en `asterisk/sounds/callcenter_manager/`.
